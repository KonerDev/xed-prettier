# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## 1.1.1 (v106) - 2026-09-10

### Maintenance

- Updated extension to reflect the latest Xed-Editor API changes.
- Updated Prettier version from `3.6.2` to `3.9.6`

## 1.1.0 (v104) - 2026-08-07

### Changed

- Refactor extension to use the new Formatter API

### Fixed

- Fixed `Format with Prettier` command not working when turned off in formatter settings

## 1.0.0 (v101) - 2026-07-12

### Added

- Format code with Prettier through commands or automatically on save
- Format whole file or selected region
- Customize code style and formatting options through settings
